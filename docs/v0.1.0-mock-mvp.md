# Checkpoint v0.1.0-mock-mvp

Data: 2026-06-14

## Objetivo

Congelar o estado demonstravel do ERP PaoBom em modo mock/in-memory, consolidando o MVP antes da entrada nas fases de DevOps minimo, testes reais, persistencia e API.

## Escopo Congelado

### Web

- Fundacao arquitetural com monorepo, DI, React Query, Zustand e EventBus
- Produtos/Insumos
- Fornecedores
- Clientes
- CRM
- Compras com custo
- Estoque rastreavel com perdas e ajustes
- Receitas versionadas
- Producao com status real
- Vendas com estoque, desconto e cancelamento
- Caixa com abertura e fechamento
- Custos e lucratividade
- Relatorios por periodo
- Dashboard executivo
- Permissoes mockadas por perfil
- Auditoria mockada

### Mobile

- Home operacional Expo/React Native
- Dashboard compacto
- Abas de acompanhamento: resumo, estoque, vendas, producao, caixa e auditoria
- Dados mockados via dominio compartilhado e DI

## Validacoes Executadas

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

Resultado esperado no checkpoint: todos os comandos passam.

## Criterios de Aceite da Fase 12

- README de projeto criado e revisado
- Comandos documentados
- Escopo do MVP mock documentado
- Limitacoes conhecidas documentadas
- Tag `v0.1.0-mock-mvp` criada no Git
- Workspace sem alteracoes de codigo pendentes da fase

## Limitacoes

- Repositories mockados/in-memory
- Sem persistencia real
- Sem API/backend
- Sem autenticacao real
- Permissoes client-side
- Auditoria nao persistente
- Testes ainda placeholders
- Mobile sem acoes transacionais
